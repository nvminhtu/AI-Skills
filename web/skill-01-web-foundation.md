## 🎯 Mục tiêu
Xây nền tảng frontend chuẩn production.

## 📂 Core Knowledge
- **Semantic HTML:** Sử dụng đúng thẻ (main, section, article, nav, aside) để cải thiện SEO và Accessibility.
- **Accessibility cơ bản:** Cung cấp aria-labels, alt text cho ảnh, và đảm bảo độ tương phản màu sắc.
- **Responsive Design:** Tiếp cận Mobile-first, sử dụng Flexbox/Grid và Media Queries.
- **CSS Architecture:** Ưu tiên utility-first (Tailwind) hoặc component-based (CSS Modules/Styled Components).
- **ES6+ JavaScript:** Sử dụng Arrow functions, Destructuring, Optional chaining, và Modules.
- **DOM Lifecycle:** Hiểu rõ các giai đoạn mount/unmount và render của trình duyệt.
- **Event Handling Pattern:** Sử dụng Event Delegation và Cleanup listeners để tránh memory leaks.

## 🛡️ AI rules
- **Luôn viết code clean, semantic.**
- **Không inline CSS.**
- **Không duplicate logic.**
