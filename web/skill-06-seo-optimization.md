# SKILL 06 — SEO Optimization System

## Skill Identity
**Name:** SEO Optimization System
**Version:** 1.0.0
**Description:** Technical SEO and programmatic content strategy to dominate organic search results.
**Trigger Requirements:**
- "tối ưu seo"
- "seo technical"
- "structured data"
- "sitemap generation"
- "organic traffic tool"

## 🎯 Mục tiêu
Build tool site tối ưu organic traffic và đạt thứ hạng cao trên Google.

## 📂 Core Knowledge
- **Dynamic Meta Tags:** Tự động tạo Title và Description hấp dẫn theo từ khóa của từng tool.
- **Structured Data (Schema.org):** Nhúng JSON-LD (SoftwareApplication, HowTo) để hiển thị rich snippets.
- **Sitemap Auto Generation:** Tự động cập nhật danh sách tool vào sitemap.xml.
- **Robots.txt:** Phân quyền crawler truy cập hợp lý.
- **Internal Linking Engine:** Hệ thống gợi ý tool liên quan để giữ chân người dùng.
- **Category Clustering:** Góm nhóm các tool theo chủ đề (ví dụ: PDF Tools, Image Tools).
- **Keyword-based Slugs:** Tạo đường dẫn (URL) thân thiện với SEO.

## 🛡️ AI rules
- **Mỗi tool phải có metadata riêng biệt và độc nhất.**
- **Tối ưu Heading structure (H1, H2, H3) theo đúng thứ tự ưu tiên từ khóa.**
- **Không duplicate content:** Tránh tạo ra các trang có nội dung giống hệt nhau.
